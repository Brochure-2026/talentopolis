❌ SOLUCIÓN DE PROBLEMAS DE PRUEBA
──────────────────────────────────

ERROR en Prueba #2 - "Python no se encontró"
──────────────────────────────────────────────
Solución:
  1. Instala Python: https://www.python.org/downloads/
  2. Elige "Windows Installer (64-bit)"
  3. IMPORTANTE: Marca ☑ "Add Python to PATH"
  4. Completa la instalación
  5. Reinicia PowerShell completamente
  6. Intenta de nuevo

ERROR en Prueba #3 - Script no se ejecuta
─────────────────────────────────────────
Solución:
  1. Asegúrate de estar en la carpeta correcta
     cd C:\Users\Lobitoxic\OneDrive\Documentos\LINEGRAVITY\TALENTOPOLIS
  2. Verifica que sync_textos.py existe
     ls sync_textos.py
  3. Intenta de nuevo: python sync_textos.py

ERROR en Prueba #3 - "Ruta no encontrada"
──────────────────────────────────────────
Solución:
  1. Abre sync_textos.py
  2. Verifica que WORKSPACE sea la ruta correcta
  3. Si la ruta contiene espacios, debe estar entre comillas
  4. Ejemplo:
     WORKSPACE = r"c:\Users\Lobitoxic\OneDrive\Documentos\LINEGRAVITY\TALENTOPOLIS"

ERROR en Prueba #4 - No se crea backup
──────────────────────────────────────
Solución:
  1. Verifica que el script se ejecutó sin errores
  2. Si hay errores, consulta el log
  3. Ejecuta el script nuevamente
  4. El backup se crea cada sincronización
